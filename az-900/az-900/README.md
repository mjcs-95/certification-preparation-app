# AZ-900 compact question bank

Short-path edition for Windows.

- 3 learning paths
- 12 modules
- 92 unit files
- 35 questions per unit
- 3,220 questions total

Naming: `p1/m01/u01.json` = learning path 1, module 1, unit 1.
`map.json` maps every compact filename to its full Microsoft Learn title and URL.
`all.json` contains the combined question bank.
